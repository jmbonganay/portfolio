# John Michael Bonganay Portfolio Hero

This is a locally hostable React/Vite starter for the first hero section of John Michael Bonganay's personal portfolio.

## Run locally

On Windows, you can double-click:

```text
start-local.bat
```

Or run the commands manually:

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

If PowerShell blocks `npm`, use:

```powershell
npm.cmd install
npm.cmd run dev
```

## Included

- React hero section using resume-based content
- Featured Work / Selected Builds section pulled from the deployed portfolio
- Category filters for Shopify, WordPress, Netlify, and advertorial work
- Short case-study modal for the strongest sales-backed and NDA-safe projects
- Local project screenshots and performance proof images in `public/work`
- Conversion-Focused Services section with service cards and delivery workflow
- Tech Stack / Tools section with grouped workflow-oriented tool categories
- Animated operating stack radar visual
- Build Process section with launch blueprint phases and QA checklist
- Contact section with direct channels, availability signals, and inquiry intent selector
- Restrained scroll-reveal animations with reduced-motion support
- Simple footer with quick navigation and direct contact links
- Favicon and social preview image metadata for link sharing
- Generated local hero background image in `src/assets`
- Downloadable resume PDF in `public`
- Responsive desktop and mobile styling
